# 🌸 최치원 오언시 눈도장 한시 암기 PWA (<우흥> · <촉규화> · <강남녀>)

신라의 대문장가 **고운(孤雲) 최치원(崔致遠)**의 대표적인 오언 명시 세 편:
1. **<우흥(寓興)>** (오언율시 8구)
2. **<촉규화(蜀葵花)>** (오언율시 8구)
3. **<강남녀(江南女)>** (오언고시 12구)

아이들이 **'시각적 눈도장 장면 연상'**과 **'리듬 챈트'**로 쉽고 즐겁게 암기할 수 있는 반응형 웹 애플리케이션(PWA)입니다.

---

## 📱 핵심 기능

1. **상단 3단 시 전환기 (Segmented Switcher):** 
   - `1. 우흥` / `2. 촉규화` / `3. 강남녀` 버튼 터치로 자유롭게 전환.
   - 인장 도장(`寓` ↔ `葵` ↔ `女`) 및 련 수(4련/6련)에 맞춰 인터페이스 자동 반응.
2. **🖼️ 눈도장 장면 연상 모드 (Visual Scene Imprint):**
   - 시마다 단계별 고화질 동양풍 수채화 스토리북 일러스트 수록.
   - **스마트 청킹(Chunking) 돋보기:** 각 글자 터치 시 훈음, 뜻풀이, 시 속 역할, 단자 음성 낭독 지원.
   - **암기 마스킹 도구:** `전체보기` / `한자만 보기` / `해석만 보기` / `빈칸시험` 지원.
   - **AI 프롬프트 복사 & 이미지 라이트박스 확대** 지원.
3. **🧩 한자 블록 맞추기 미니 퀴즈 (Block Quiz):**
   - 10개의 흩어진 한자 우드 블록을 순서대로 맞춰 2구를 완성하는 놀이형 인터랙티브 퍼즐.
   - 탭 사운드, 오답 시 흔들림(shake) 피드백, 정답 시 전통 5음계 차임과 꽃가루 축하 파티클.
4. **🎵 전체 낭독 & 챈트 모드 (Rhythmic Sing-along):**
   - 브라우저 Web Audio API로 전통 목탁/장단 비트를 생성하여 리듬감 있는 합송 가이드 제공.
   - 속도 조절(0.85x, 1.0x, 1.15x) 및 실시간 하이라이팅.
5. **📖 한시 깊이 알기:**
   - 최치원 선생의 생애, 각 시의 창작 배경과 아이들을 위한 4대 교훈 스토리.
6. **📲 모바일 PWA 오프라인 지원:**
   - `manifest.json` 및 `sw.js` 탑재로 홈 화면 추가 및 오프라인 학습 지원.
